Known implementation choices:
  Vector provides dynamic array allocation; no raw new[]/delete[] is required.
  Zero-length arrays are supported.
  Text input is one UTF-8 line, with optional BOM and terminal LF/CRLF.
  Characters mean Unicode code points; no grapheme grouping or case folding.
  Existing output files are overwritten after path/input checks.
  File writes are checked but are not transactional or power-loss-safe.
  Full native Windows execution remains unverified due to Application Control.
